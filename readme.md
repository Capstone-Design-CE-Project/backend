문장에서 주어 동사 형용사등을 추출하고 추가작업을 하는 함수
postprocess_kkma_pos
처음 kkma로 추출한 결과를 보벙하기위해 okt로 추출내용을 처리하는 함수
사용이유
개가 뛰고있다 라는 문장에서 주어를 개로 생각하고 있는데 kkma만 쓸 경우 (개가:Noun)으로 추출하는 결과가 발생 원하는 결과는 (개:Noun) 이므로 보정하는 처리가 필요함
전체적인 흐름
문장 분리 -> 추출&보정 -> 저장 객체 생성및 반환 -> 리스트 저장의 순서로 진행됨
질문과 답변의 형식의 경우
질문 분리 -> 명사 추출 -> 저장된 객체중 탐색 -> 존재한다면 current_noun으로 저장
답변 분리 -> 추출 ->{명사 존재:객체가 반환 ,명사 비존재:형용사와 동사의 리스트만 반환}->
{객체 반환:명사 비교후 없으면 추가 있으면 형용사 동사만 전에있던 객체에 추가,리스트 반환:current_noun에 저장된 객체에 추가}
